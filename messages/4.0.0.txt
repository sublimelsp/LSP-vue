# Breaking change

This version uses the Vue Language Server 4, which works with TypeScript 7.

- LSP-vue now needs LSP-tsgo instead of LSP-typescript. Install LSP-tsgo from Package Control.
- TypeScript features in Vue files come from LSP-tsgo through the `@vue/content-mapper` package. Install it and
  TypeScript 7.1 or later in your project, add it to the `contentMappers` field of your tsconfig and enable
  `runExternalCode` in the LSP-tsgo settings of the project.
- The `vueCompilerOptions` field of the tsconfig is no longer read. Move the options to the `options` of the
  `contentMappers` entry.
- `vue-tsc` is replaced by `tsc --runExternalCode`.
- The server doesn't provide semantic tokens. Component tags get their color from the syntax.
- If you override `disabled_capabilities` in your user settings, include `definitionProvider`,
  `referencesProvider`, `renameProvider` and `typeDefinitionProvider`, or remove the override. Sublime Text
  replaces the whole setting, so a partial override sends these requests to the Vue server, which returns no
  results.

See the README for the details.
